What these toolkits collect

Sole gives partner organisations free, self-contained planning tools to hand to their members. This page answers the question those members' governance teams always ask.

Verified 7 August 2026 · Applies to the Sole white-label toolkits

Nothing.

No data leaves the page. Nothing is stored on the reader's device, nothing is sent to Sole, and nothing is sent to any third party. There is no analytics of any kind. Member data never touches a commercial vendor, because there is no channel for it to travel down.

What the tool actually does

It's a single HTML file. The reader answers a few multiple-choice questions and the page builds them a prioritised plan. Every answer lives in the browser's memory for as long as the tab is open, and is gone the moment it's closed or reloaded.

Verified absent

  • No cookies, no localStorage, no sessionStorage, no indexedDB — nothing written to the device
  • No analytics — no Google Analytics, Tag Manager, Meta pixel, PostHog, Mixpanel, Segment, Plausible, Hotjar or Clarity
  • No network calls — no fetch, XMLHttpRequest, sendBeacon or WebSocket anywhere in the file
  • No forms — nothing to submit, no email capture, no mailto: handoff
  • No third-party requests at all — not even web fonts. The file uses the reader's own system fonts precisely so that no outside party ever sees them open it.

Present, and worth naming

  • One optional free-text box ("what kind of work is it?"). It is read into memory to personalise a sentence, and is never transmitted.
  • Links to ato.gov.au, ndis.gov.au, business.gov.au and similar, plus one link to Sole. These only load if the reader chooses to click them — the same as any link in any document.

Don't take our word for it — two-minute check

  1. Turn off the wifi and open the file. It loads and runs to completion. A tool that phoned home couldn't.
  2. Open your browser's developer tools, Network tab, and reload. You'll see requests for the file itself and nothing else. No third-party domains appear.
  3. Read the source. It's one plain, unminified file. Search it for fetch, localStorage, cookie, gtag or analytics — there are no matches.
Why we built it this way. A tool your members can open without being counted is worth more to them than the numbers we'd get from counting. If we ever need to measure how a partnership is going, we'll do it on our own website, at the point someone chooses to click through to us — never inside the tool.

Scope

This statement covers the self-contained white-label toolkits Sole distributes to partners, including the Small business launch toolkit (business-launch-toolkit.html and the branded exports generated from it). Each is a single file with no server component and no backend.

It does not cover the Sole application at soleapp.com.au, which is a normal signed-in product with its own privacy policy — that applies only if a reader chooses to click through and create an account.
